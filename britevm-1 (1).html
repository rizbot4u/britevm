Under the Hood

What is EVM and why does it matter?

EVM stands for Ethereum Virtual Machine. Think of it as the global computer that runs the internet of money. It's a shared system — thousands of computers around the world run it simultaneously — and nobody owns it.

When you send money using BriteVM, you're not asking a bank to move a number in their database. You're writing a transaction onto a public, permanent ledger that every participant in the network can verify. No middleman. No trust required.

BriteVM is built on Base — an EVM-compatible blockchain developed by Coinbase. Base inherits Ethereum's security while processing transactions 10x faster and 100x cheaper. The same code that runs on Ethereum runs on Base, unchanged.

This is why crypto remittance is fundamentally different from PayPal or Wise. Those services are still moving money through the old banking rails — they just put a nicer app on top. BriteVM moves value directly, peer to peer, with no rails in between.

DeFi 101

What is a swap? How does it work?

🏊

Liquidity Pools — the engine

Instead of a traditional exchange with buyers and sellers, swaps use liquidity pools — smart contracts holding two tokens. Anyone can deposit tokens to earn fees. BriteVM's pool holds our token paired with USDC on Uniswap V4.

🤖

Automated Market Maker (AMM)

A smart contract sets the price automatically using a simple formula: as you buy one token, it becomes more expensive. No humans, no order books, no manipulation. The math runs 24/7 on the blockchain.

⚡

Atomic Execution

When you swap, the entire transaction happens in one block — one moment in time. Either everything completes, or nothing does. You can never be left with half a transaction. This is what "trustless" actually means.
